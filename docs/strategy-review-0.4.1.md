### 2.5 lua_momentum 🔴 退役（从生产可启用面摘除，保留文件作教学示例）

- **机制**：单 tick 价格移动确认的动量追进。
- **历史**：出厂分类器校准 bug 实锤（2026-09-30：单 tick % vs 0.04 阈值 ≈ 每 tick 确认、无窗口）；momentum-v2 重构 72 臂全负不采纳；60s 盘口节奏实测定场（15m 信号粒度 = 60s，策略应走 kline）。

- **处置**：**退役**——不删文件（E30 示例/教学价值），但 manifest description 与 README 明示「复亮点火后 −$17.6k，勿在生产启用」；从任何默认/推荐启用集摘除。救活 = 新策略研发（窗口化确认 + 被动挂单 + kline 粒度），不是调参。
