## 2. 未用依赖清理

**工具可用性说明（诚实归档）**：`cargo +nightly udeps` 需要 nightly 工具链。本机为 Homebrew rust 1.97.1（无 rustup，装 nightly 会影响用户环境），因此 udeps 输出无法产生。等效证据链为：

1. `cargo machete`（静态 Cargo.toml 级检测）指认候选；
2. 逐项 `grep -rn "依赖名"` 核对源码零引用；
3. 删除后 `cargo check --all-targets --workspace` 全目标编译通过（引用会被编译器拒绝）；
4. 复跑 machete 清洁。

已删除 9 项：

- `blitzkrieg_core`：tokio-util、tokio-tungstenite、futures、futures-util、thiserror
- `blitzkrieg-market-api`：tokio（sync feature）
- `polymarket-extension`：async-trait、serde（直接依赖；走 workspace 透传）、thiserror；futures → 仅保留 `futures-util`（`venue.rs` 的 `StreamExt` 与 `feed.rs` 的 WS 在用），tokio-tungstenite 保留（binance WS feed）

`Cargo.lock` 145,881 → 145,725 字节。
