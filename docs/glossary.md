# 术语表

本页用日常语言解释文档里出现的术语。**第一次见到不认识的词，先查这里。**

| 术语 | 一句话解释 |
|---|---|
| **账本（Ledger）** | 系统里唯一记录「你有多少钱」的地方。所有盈亏都以它为准。 |
| **余额（balance）** | 账本里的总额。**已经包含了被冻结的那部分。** |
| **冻结（reserved）** | 挂在未成交订单上的钱。它还在你的余额里，但暂时不能拿去下新单。 |
| **可用（available）** | `balance − reserved`。真正能拿去下新单的钱。 |
| **期初权益（openingEquity）** | 一天开始时的权益。累计净 PnL 从它算起。 |
| **累计净 PnL** | `balance − openingEquity`。**不要再减 frozen、也不要再加 reserved**，加一次就是重复计算。 |
| **AccountGate（闸门）** | 一个账户能不能下新单的唯一开关。它只有一个状态：开或关，关着就带一个原因。 |
| **解冻（unfreeze）** | 把闸门重新打开的**唯一动词**。重启进程也会清掉会话级的冻结。 |
| **退出原因（exit reason）** | 这笔仓位为什么被卖掉：止盈、跟踪止盈、止损、时间到、策略信号等。 |
| **止盈（take_profit / TP）** | 涨到预设盈利就卖。 |
| **跟踪止盈（trailing stop）** | 先让盈利跑，从最高点回落一定幅度再卖。两个参数：**武装点**（涨到多少才开始跟踪）、**让回幅度**（从最高点回落多少就卖）。 |
| **盈亏比（RR）** | 平均每笔盈利 ÷ 平均每笔亏损。小于 1 表示赢的时候赚得比输的时候少。 |
| **胜率（WR）** | 盈利笔数 ÷ 总笔数。 |
| **回撤（MDD）** | 从最高点到最低点的最大损失幅度。 |
| **语料（corpus）** | 回放用的历史行情数据。每份语料都有 sha256，改了就不能用。 |
| **影子进化（shadow evolution）** | 系统自动微调策略参数的一套机制。它只出提案，不自动上线。 |
| **OME · Song** | 订单执行组件，代号 Song。 |
| **backtest · Stone** | 回测组件，代号 Stone。 |
| **UI · PonyYiDan** | 界面组件（TUI + WebUI），代号 PonyYiDan。 |
